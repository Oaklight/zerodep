# S3 存储

零依赖的 S3 兼容存储客户端（AWS Signature V4）。

> **替代:** `boto3`、`minio`、`s3fs`

## 概述

最小化的 S3 REST 客户端，覆盖常见对象存储操作。兼容 AWS S3、Cloudflare R2、Oracle Object Storage、MinIO 及其他 S3 兼容后端。仅使用 Python 标准库。

| 文件 | 说明 | 依赖 |
|------|------|------|
| `s3.py` | S3 客户端（SigV4 认证） | 无（仅标准库：`hashlib`、`hmac`、`http.client`、`urllib.parse`、`xml.etree`） |

## 主要特性

- **桶操作** -- `bucket_exists`、`make_bucket`、`remove_bucket`、`list_buckets`
- **对象操作** -- `get_object`、`put_object`、`stat_object`、`remove_object`、`copy_object`、`list_objects`
- **AWS Signature V4** -- S3 兼容服务的标准认证
- **URL 风格** -- 路径风格（`endpoint/bucket/key`）和虚拟主机风格（`bucket.endpoint/key`）
- **流式传输** -- 通过 `iter_chunks()` 分块下载
- **多供应商** -- 开箱即用支持 AWS S3、Cloudflare R2、Oracle OCI、MinIO

## 使用方式

```bash
cp s3/s3.py your_project/
```

## 使用示例

### AWS S3

```python
from s3 import S3Client

client = S3Client(
    endpoint="s3.amazonaws.com",
    access_key="AKIA...",
    secret_key="wJal...",
    region="us-east-1",
)

# 上传
import io
data = b"hello world"
client.put_object("my-bucket", "hello.txt", io.BytesIO(data), length=len(data))

# 下载
response = client.get_object("my-bucket", "hello.txt")
try:
    print(response.read())
finally:
    response.close()

# 列出对象
for obj in client.list_objects("my-bucket", prefix="data/"):
    print(obj.key, obj.size)
```

### Cloudflare R2

```python
client = S3Client(
    endpoint="<account>.r2.cloudflarestorage.com",
    access_key="...",
    secret_key="...",
    region="auto",
    url_style="path",
)
```
