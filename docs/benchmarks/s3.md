# S3 Storage Benchmark

Apple-to-apple performance comparison between zerodep s3 and [`boto3`](https://pypi.org/project/boto3/) / [`minio`](https://pypi.org/project/minio/).

!!! info "Test Environment"
    - **CPU:** x86_64 Linux
    - **Python:** 3.12
    - **Tool:** pytest-benchmark 5.2.3 (mean values reported)
    - **Reference:** boto3, minio
    - **Last Updated:** 2026-09-28

## Implementations

| Implementation | File/Package | Description |
|----------------|--------------|-------------|
| **zerodep** | `s3.py` | stdlib-only S3 client with SigV4 |
| **boto3** | *(reference)* | AWS official SDK |
| **minio** | *(reference)* | MinIO Python client |

## Tests Performed

| Test | Description |
|------|-------------|
| Put Object (Small/Medium/Large) | Upload 1KB / 100KB / 1MB objects |
| Get Object (Small/Medium/Large) | Download 1KB / 100KB / 1MB objects |
| Bucket Exists | Check bucket existence |
| Make Bucket | Create a bucket |
| Stat Object | Get object metadata |
| List Objects (Small/Medium/Large) | List 10 / 100 / 1000 objects |
| Copy Object | Server-side copy |
| Remove Object | Delete an object |
| Cross Validation | Verify data integrity across implementations |

## Run It Yourself

```bash
pip install pytest pytest-benchmark boto3 minio
pytest s3/test_s3_benchmark.py --benchmark-only -v
```
