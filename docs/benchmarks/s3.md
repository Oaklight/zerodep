# S3 存储基准测试

zerodep s3 与 [`boto3`](https://pypi.org/project/boto3/) / [`minio`](https://pypi.org/project/minio/) 的同类性能对比。

!!! info "测试环境"
    - **CPU:** x86_64 Linux
    - **Python:** 3.12
    - **工具:** pytest-benchmark 5.2.3（报告均值）
    - **参考库:** boto3、minio
    - **最后更新:** 2026-09-28

## 实现

| 实现 | 文件/包 | 说明 |
|------|---------|------|
| **zerodep** | `s3.py` | 仅标准库的 S3 客户端（SigV4） |
| **boto3** | *（参考库）* | AWS 官方 SDK |
| **minio** | *（参考库）* | MinIO Python 客户端 |

## 测试项目

| 测试 | 说明 |
|------|------|
| 上传对象（小/中/大） | 上传 1KB / 100KB / 1MB 对象 |
| 下载对象（小/中/大） | 下载 1KB / 100KB / 1MB 对象 |
| 检查桶存在 | 检查桶是否存在 |
| 创建桶 | 创建新桶 |
| 对象元数据 | 获取对象元数据 |
| 列出对象（小/中/大） | 列出 10 / 100 / 1000 个对象 |
| 复制对象 | 服务端复制 |
| 删除对象 | 删除对象 |
| 交叉验证 | 跨实现数据完整性验证 |

## 自行运行

```bash
pip install pytest pytest-benchmark boto3 minio
pytest s3/test_s3_benchmark.py --benchmark-only -v
```
