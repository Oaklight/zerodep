httpclient

tier: subsystem network v1.4.2 View source

A zero-dependency HTTP/1.1 client built on http.client from the standard library. Supports connection pooling, automatic retries, streaming responses, authentication, and both sync and async modes.

📝 Note

This module shadows the stdlib http.client module. If you need both, import httpclient as a package alias: import httpclient as hc.

Installation

Copy httpclient.py into your project:

bash 
zerodep add httpclient

Or manually copy the file from the repository.

Quick Start

python 
from httpclient import HttpClient

client = HttpClient(base_url="https://api.example.com")

# Simple GET
resp = client.get("/users/1")
print(resp.status_code)  # 200
print(resp.json())        # {"id": 1, "name": "Alice"}

# POST with JSON
resp = client.post(
    "/users",
    json={"name": "Bob", "email": "bob@example.com"},
)
assert resp.status_code == 201

# File upload
with open("photo.jpg", "rb") as f:
    resp = client.post("/upload", files={"file": f})

client.close()
python 
import asyncio
from httpclient import AsyncHttpClient

async def main():
    async with AsyncHttpClient(
        base_url="https://api.example.com"
    ) as client:
        resp = await client.get("/users/1")
        print(resp.json())

        # Concurrent requests
        results = await asyncio.gather(
            client.get("/users/1"),
            client.get("/users/2"),
            client.get("/users/3"),
        )

asyncio.run(main())

API Reference

HttpClient

class HttpClient(base_url=None, *, timeout=30.0, retries=3, headers=None, auth=None, verify_ssl=True, pool_size=10)

Synchronous HTTP client with connection pooling.

Parameters

ParameterTypeDefaultDescription
base_url str | None None Base URL prepended to all request paths.
timeout float 30.0 Default request timeout in seconds.
retries int 3 Number of retry attempts for transient errors (5xx, connection errors).
headers dict[str, str] | None None Default headers merged into every request.
auth tuple[str, str] | str | None None Basic auth tuple (user, pass) or Bearer token string.
verify_ssl bool True Whether to verify SSL certificates.
pool_size int 10 Maximum number of connections per host.

Methods

get(url, *, params=None, headers=None, timeout=None) → Response

Send a GET request.

post(url, *, data=None, json=None, files=None, headers=None, timeout=None) → Response

Send a POST request. Provide one of data, json, or files.

put(url, *, data=None, json=None, headers=None, timeout=None) → Response

Send a PUT request.

patch(url, *, data=None, json=None, headers=None, timeout=None) → Response

Send a PATCH request.

delete(url, *, headers=None, timeout=None) → Response

Send a DELETE request.

stream(method, url, *, chunk_size=8192, **kwargs) → Iterator[bytes]

Stream a response in chunks without loading the entire body into memory.

Response

class Response

Represents an HTTP response. Not instantiated directly.

Attributes

AttributeTypeDescription
status_code int HTTP status code (200, 404, etc.)
headers dict[str, str] Response headers (lowercase keys).
content bytes Raw response body.
text str Response body decoded as text.
encoding str Detected or declared character encoding.
ok bool True if status code is 2xx.
url str Final URL after redirects.

Methods

json(**kwargs) → Any

Parse response body as JSON.

raise_for_status() → None

Raise HTTPStatusError if the response is 4xx or 5xx.

Exceptions

ExceptionWhen raised
HTTPError Base class for all httpclient exceptions.
HTTPStatusError Response status is 4xx or 5xx (raised by raise_for_status()).
ConnectError Failed to establish a connection.
TimeoutError Request exceeded the configured timeout.
TooManyRedirects Exceeded maximum redirect limit (default: 10).

Advanced Usage

Custom retry logic

from httpclient import HttpClient, RetryConfig

client = HttpClient(
    retries=RetryConfig(
        total=5,
        backoff_factor=0.5,
        status_forcelist={429, 500, 502, 503, 504},
        allowed_methods={"GET", "POST"},
    )
)

Session hooks

def log_request(request):
    print(f"→ {request.method} {request.url}")

def log_response(response):
    print(f"← {response.status_code} in {response.elapsed:.3f}s")

client = HttpClient(
    hooks={
        "request": [log_request],
        "response": [log_response],
    }
)
